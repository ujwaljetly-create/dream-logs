# Dream Logs

Dream Logs is a social AI dream journal that turns a user's dream description into visual stories and, later, AI-generated dream movies.

## Product vision

Users can describe a dream, select consenting people from their Dream Cast or add photos, generate a visual Dream Story, and publish it privately, to friends, or publicly. Friends can be tagged, users can follow or subscribe to Dream Logs, and public dreams can be discovered in a social feed.

## Planned stack

- Flutter
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
- Python/FastAPI AI backend
- Image generation first; video generation in a later milestone

## MVP milestones

1. Flutter foundation and Dream Logs design system
2. Authentication and onboarding
3. Profiles and Dream Cast
4. Friends/follows
5. Dream creation
6. AI Dream Story generation
7. Publishing and feeds
8. Tags, likes, comments, and notifications
9. AI Dream Movie generation
